# 主体影像工坊

> 将真实摄影与编辑设计语言结合，让一张照片同时呈现主体原貌与艺术重构。

**主体影像工坊**（Subject Editorial Poster）是由 **AI十三** 维护的图片编辑 skill。它以单张照片为唯一内容来源，在严格保持原图尺寸、比例与方向的前提下，生成具有精品刊物、摄影专题和当代艺术展览气质的主体艺术海报。

成品上下严格按 50:50 分配：上半保留摄影真实性，下半以拼贴、丝网印刷痕迹和设计草图重新演绎同一主体。整个流程不依赖主体类别，人物、动物、产品、建筑、植物及自然景物等均可按照同一视觉规则处理。

## 核心特性

| 特性 | 说明 |
| --- | --- |
| 原图尺寸输出 | 保持原图宽度、高度、宽高比和方向，不裁切、不拉伸、不扩展画布 |
| 单图内容来源 | 每次仅使用一张源照片，不混合其他图片或引入无关主体 |
| 上下双区结构 | 两个区域严格各占画面的 50%，并围绕同一主体展开 |
| 摄影真实保留 | 上区维持主体特征、环境细节、光照、色彩、比例、透视与位置关系 |
| 艺术化重构 | 下区结合纸张底色、半透明色块、局部照片肌理、细绘线与印刷痕迹 |
| 克制版面信息 | 仅添加代表主体的英文标题与年份，不添加水印或多余装饰文字 |
| 单一成品交付 | 每次只输出一张完整海报，不生成多版本、过程图或四宫格 |

## 视觉处理规则

### 上半区域：真实摄影

- 保留主体、陪体与环境之间的比例、透视和位置关系。
- 不重建、不移动、不删除、不替换核心元素。
- 仅进行精细调色和极轻、几乎不可见的胶片颗粒处理。
- 避免夸张改色、明显滤镜、过度锐化与塑料质感。

### 下半区域：艺术重构

- 以连续的暖米色纸张为背景，重构原图中的同一主体及其所在场景。
- 使用半透明色块、交叠矩形、纤细绘图线、轻微网点或丝网印刷痕迹组织画面。
- 保留主体轮廓与识别特征，使摄影肌理与设计草图自然融合。
- 保留充足空白和明确视觉中心，避免元素铺满画面。
- 底部以淡色竖向长条或细线逐渐淡化，形成安静的视觉收尾。

### 标题与年份

- 英文标题位于下区左上角，使用 **2–3 个单词**、细衬线字体和较宽松的字距。
- 年份位于下区右上角，使用小字号呈现。
- 年份优先采用用户提供或照片中明确显示的信息；没有相关信息时使用当前年份。
- 除标题和年份外，不添加 logo、水印、标签、边框文字或说明段落。

## 处理流程

```text
读取单张源照片
       ↓
识别主体、陪体、环境与关键特征
       ↓
保持原图尺寸，建立上下各 50% 的画面结构
       ↓
上区保留真实摄影，仅进行轻微色彩与颗粒优化
       ↓
下区提取主体特征，完成拼贴与草图式重构
       ↓
加入英文标题与年份，检查输出规范
       ↓
交付一张完整主体艺术海报
```

## 安装与调用

将包含本文件的 skill 文件夹放入 Codex 可发现的 skills 目录，然后使用以下名称调用：

```text
$subject-editorial-poster
```

上传一张照片并提出制作需求即可。例如：

```text
使用 $subject-editorial-poster 将这张照片制作成主体艺术海报。
保持原图尺寸，上半保留真实摄影，下半进行拼贴与草图式重构。
```

如有明确年份，也可以直接补充：

```text
使用 $subject-editorial-poster 处理这张照片，年份使用 2025。
```

## 输出规范

生成结果应同时满足以下条件：

- 仅包含一张完整海报，且内容来自同一张源照片。
- 成品的宽度、高度、宽高比和方向与原图一致。
- 上下区域严格各占 50%，主体与场景保持一致。
- 上区核心元素未被重建、移动、删除或替换。
- 下区能够辨识原图主体，并体现纸张、拼贴、印刷和草图质感。
- 标题为 2–3 个英文单词，年份位置与字号符合要求。
- 不包含多余文字、水印、无关主体、多个版本或过程展示。
